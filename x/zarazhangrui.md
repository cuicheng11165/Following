### Opinions and takes

- 未来：不打字、不写文档，说话即执行，延迟趋零
- AI-native 公司文化像开源社区
- 厚 context、薄 prompt；有时只描述问题不给方案，模型反而更好
- 招聘：Round1 无 AI 测领域；Round2 必须用 AI 完成项目并审 transcript
- 公司不配工具时，最强员工会自费把公司数据打进外部工具
- 纯 agent 单人模式会削弱团队文化 → 需要 human-human-agent
- 「Do not do X in order to do Y. Just do Y.」
- 企业最大障碍是 AI 与业务理解的错位；应建立个人 eval set
- 软件可以是一次性的 playground / dashboard

   认为当前 #1 需求是速度：智能已够好，但每任务等 1–5 分钟落在「太短没法深工作、太长只能干瞪眼」的最糟区间，于是人去刷 X。断言 agents 正在让所有人更 ADHD。  
   链接：https://x.com/zarazhangrui/status/2080829737044439444

3. **Agent 后创立 vs 改造型公司**  
   划分两类公司：coding agents 出现前成立、忙着 retrofit 的，与之后从零建的。后者天生不同：团队常不到十人、按项目而非部门组织、每人闭环自己的工作、几乎没有内部会议。  
   链接：https://x.com/zarazhangrui/status/2079225776545968166

4. **创业可同时发明业务与组织**  
   接续上帖：今天开公司最兴奋的一点，是你不只发明新业务，还可以发明一种新的组织类型——把「AI-native org design」抬到与产品同等重要。  
   链接：https://x.com/zarazhangrui/status/2079956443223269583

5. **招聘两轮：无 AI + 必须用 AI**  
   若她今天招聘：Round1 线下禁用 AI，测领域知识与即时判断；Round2 项目必须靠 AI 才能完成，评估结果与和 agent 的 chat transcript——同时测人与「人+agent」系统。  
   链接：https://x.com/zarazhangrui/status/2079409165424799889

6. **最强员工自费买工具 → 数据风险**  
   反复观察到的模式：最 AI 驱动的员工会自掏腰包买最好的工具；公司若不提供，最优人才就会用个人卡把公司数据灌进外部工具——IT 采购失败直接变成安全/合规问题。  
   链接：https://x.com/zarazhangrui/status/2079217955737637352

7. **可抛弃的代码/软件**  
   主张习惯「软件可以是一次性的」：为自己微调设计的 playground、帮助理解代码的 HTML 页、一次性检查用的 throwaway dashboard——用完即弃，降低对「永久正确架构」的执念。  
   链接：https://x.com/zarazhangrui/status/2078835308905578660

8. **Human-human-agent 协作**  
   讲一位超级 agent-pilled 创始人给全员 Codex Max 后的副作用：大家整天只跟 Codex 说话，人与人交流减少、会议取消、团队文化变差。企业 AI 若停留在 single-player，会牺牲协作；需要从 human-human、human-agent 走向 **human-human-agent**。  
   链接：https://x.com/zarazhangrui/status/2075004775436005687

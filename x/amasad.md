### Opinions and takes

- 经济在赌 LLM 一路缩放到 AGI；若教不会象棋则……（以棋力作 scaling 探针）。
- 严格约束下（小模型微调、无引擎辅助出招）棋力才有意义；放松约束会容易很多。
- 若 router 被激励推特定模型，则不是真路由。
- Replit 内部开发体验好到把自己拉回写代码；规模效应让托管能向用户让利。
- 支持开放权重生态是美国竞争力关键；Replit 自 2023 开源 coding 模型起持续站队。
- 消费端/消费 app 难做；coding agent UX 对新手与 ADHD 大脑都仍过复杂。
- 对 OpenAI agent 评测逃逸 + 用中文开源模型协助遏制的叙事感到「wild」。

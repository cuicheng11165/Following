#### 4. **"Local hands": cloud brain, local files**

**链接：** https://x.com/trq212/status/2107229483015258493
**时间 / 互动（如有）：** Mon, 05 Oct 2026 22:00:33 GMT; Likes=1276 Replies=128 Views=118539

##### 主帖在说什么

Dan Fein announced that a Claude Projects cloud session can connect to a folder you approve on your computer: the session stays in the cloud and only touches that folder when a task needs it, reading and editing in place, starting to roll out that day. Thariq names the pattern "local hands": Claude runs in the cloud but can access local files, and he says the same pattern is coming to Cowork. The day before, on a Latent Space clip, he had already said Claude's "brains" are moving to the cloud while it gets "local hands" on your computer. In the same Projects thread he later answers that there is no extra charge, that work can continue after you turn the computer off, and that the files are not in a remote sandbox but more like a network-mounted filesystem. He also says Cowork is the local-hands case, while other remote products can use sandboxes. The offline caveat he states on the Latent Space thread: if Claude can only see files while the computer is online, it is blocked until you are back, and a sync would have edge cases. https://x.com/trq212/status/2107580785456976085 https://x.com/trq212/status/2107257948586328450 https://x.com/trq212/status/2107242585517629483 https://x.com/trq212/status/2107557720186609711 https://x.com/trq212/status/2107558717600440421 https://x.com/trq212/status/2107580787277340835

##### 要点

- Pattern name: "local hands."
- Split: session in the cloud, files on a machine you approve.
- Coming to Cowork, not only Projects.
- Price answer in-thread: no extra charge.
- Availability answer: the session can keep working when the computer is off.
- Implementation answer: network-mounted files, not a remote sandbox. Cowork is this pattern; other remote products can use sandboxes.
- Open problem he names: an online-only mount blocks the agent while the machine is off, and sync has edge cases.

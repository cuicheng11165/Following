#### 2. **Six reasons the applied AI layer is huge**

**链接：** https://x.com/levie/status/2089921630650925170  
**时间 / 互动：** Wed 19 Aug · Likes 554 · Views ~114k

##### 主帖在说什么

Value between model and end-user workflow is larger than assumed. Six durable surfaces: (1) harness + UX variants (chat vs background agent vs dozens more); (2) domain data/systems; (3) vertical change management; (4) multi-model + post-train; (5) domain evals with a crazy long tail; (6) pricing abstractions above tokens.

##### 要点

- Model does heavy lifting; diffusion work is still massive
- Evals are “nearly impossible for one system to be tuned for all of”
- Pricing must match industry consumption, not raw tokens

#### 3. **Don’t give up on being an expert**

**链接：** https://x.com/levie/status/2090278256306229675  
**时间 / 互动：** Thu 20 Aug · Likes 442 · Views ~110k

##### 主帖在说什么

Quotes Uncle Bob on how much work it is to wrestle agents. Levie: experts currently have the upper hand. AI makes it 10× easier to *start*; judgment, steering, review, and taste of “good” still require field skill. AI will *exacerbate* skill gaps because experts have more leverage.

##### 要点

- Onboarding is easy; directing the agent is not
- Skill can be learned faster with AI, but expertise still compounds
- Same pattern will hit law, research, finance, not just coding

##### 回复中的有价值观点

Uncle Bob’s quoted post is the prompt: agent work is still hard, focused software engineering — even if you barely look at the code.

##### 一句话概括

Agents raise the ceiling for experts more than they flatten the field.

#### 3. **Why agent diffusion will be uneven**

**链接：** https://x.com/levie/status/2086559201053294909  
**时间 / 互动：** Sun 09 Aug · Likes 334 · Bookmarks 288

##### 主帖在说什么

Coding went vertical because value = unbounded digital output. Sales/legal/medicine need human feedback loops. Future volume should be background agents (every contract, every CRM signal) — but that requires rewiring processes. Factory’s Matan: if everyone called in sick, tokens would collapse.

##### 要点

- Coding is the exception, not the template
- Change management + data cleanup are the real work
